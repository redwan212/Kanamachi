# Kanamachi

A 2D online multiplayer game inspired by the traditional Bangladeshi folk game Kanamachi.

## Structure

- `game-client/` — Unity 2D project
- `game-server/` — Spring Boot backend (added in Phase 4)
- `docs/` — architecture, diagrams, API docs

## Current Status: Phase 1 (V0.1 Prototype)

Goal: two local players, one becomes Kanamachi, basic catch, round restarts.

See `docs/PHASE1_NOTES.md` for setup instructions.
